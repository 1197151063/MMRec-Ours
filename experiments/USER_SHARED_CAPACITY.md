# 不使用 ID 距离，让相关用户自然接近

## 已有证据能支持什么

用户提供的 report (3).json 中，full_shared_items、2 hops、offset=1 的抽样结果：
相邻用户可达率 0.4248046875，活跃度匹配对照 0.0205078125。
四跳可达率提高到 0.904296875，但匹配对照也达到 0.8583984375，
说明单纯增加可达性很快失去选择性，不等于找到更有用的近邻。

report (4).json 在同一个共同物品、用户度和总重叠数量上做匹配，并移除所有共同物品后，
offset=1 的剩余历史相似度差（近 ID 减远 ID）：视觉 -0.0038266，文本 -0.0003983，
协同 +0.0056387，后者描述性区间跨零。它不证明永远不存在可恢复的结构，
但不支持“近 ID 用户具有强而独立的剩余语义相似性”。

ID 距离只用于事后诊断，不用于训练正样本、图权重、挑图指标、蒸馏标签或 loss。
图与超参数以 TRAIN 内部预测或验证推荐效果选择。若要提出更一般的结论，
需要新数据集/新划分上的独立验证，不能反复以近 ID 命中率筛选结构。

## 优先候选：共享物品基底，而非扩大独立用户表

令 Z_i 为物品可训练的偏好基底，可用图文特征通过共享编码器构成，也可加入一个
明确报告的物品残差。构造：

    w_ui = R_ui * (degree_i + 1)^(-beta)
    h_u = sum_i w_ui Z_i / max(sum_i w_ui, eps)
    e_u = h_u + gamma_u * delta_u

对于两个用户，其差异为：

    e_u - e_v = sum_i (wbar_ui - wbar_vi) Z_i
                + gamma_u delta_u - gamma_v delta_v

于是共享历史直接造成共享参数和梯度；无需知道 ID 是否接近。也不能保证只共享一个物品
但其余历史很不同的用户完全接近。普通均值 beta=0 是必要对照，流行度抑制 beta>0
可能同时压掉当前数据中的有用共现信号，不能默认越强越好。

关键差异：
- 原 REARM：历史均值初始化一个独立高维用户参数表，随后可自由漂移。
- 本次已实现 history residual：固定历史语义持续输入共享投影，另有 64 维自由残差。
- 此处提出的共享物品基底：用户偏好始终由同一套当前物品基底聚合生成，不再独立漂移。

这种用户历史聚合本身与已有隐式反馈/图推荐方法密切相关，不能仅凭重写成矩阵乘法
声称新颖或没有消息传递；它本质上仍有一次 item-to-user 聚合。

## 防止个体容量破坏共享结构

优先把容量加到共享 item encoder，再比较：
1. 无用户自由残差；
2. 小的、受 L2 约束的 residual；
3. 原大小自由 residual。

若采用度自适应门控，可预先规定 gamma_u=sqrt(n_u/(n_u+c))：
稀疏用户更多依赖共享表示，历史丰富用户允许更大个性偏差。
这是待验证假设，不是从现有报告已经推导出的最优门控。

只做 pairwise 拉近 loss 也能使用训练关系，但纯吸引有塌缩风险，且本项目此前 UU
约束收益有限。持续共享参数提供更直接的归纳偏置，不应把同一旧 loss 换名再次当新方案。

## 备选：语义兴趣原型

从 item 特征学习共享的兴趣原型/软分配，按用户 TRAIN 历史聚合成兴趣混合权重，
再由共享原型生成用户表示。相似消费分布可产生相似用户表示，不依赖 ID。
需要防止只有一两个热门原型主导，以及共享一个泛化主题就把大量用户错误拉近。
原型数、分配温度和是否有效，仍以推荐验证指标选取。

## 容量实验与这一问题的关系

preferences / preferences_extended 实现的是历史持续输入、低维残差、
投影容量和候选相关多兴趣。后续新增的 shared_users / shared_users_extended
已实现动态物品基底聚合、相对范数有界残差及度自适应门控，见 REARM_SHARED_USERS.md。
多兴趣 code 仍是独立用户参数，它可能增强个性化，也可能减弱近邻相似性；
不能把多兴趣实验描述为已经解决了近 ID 用户距离问题。

后续应同时观察推荐精度与：
- 共享物品用户之间的 embedding 距离；
- 控制活跃度后的非共享用户距离；
- 近 ID vs 同结构远 ID 的差异（只作诊断）；
- 残差范数占比、全体表示方差和兴趣头相似度。

所有用户都接近是塌缩，绝非目标。无 ID 信号的模型只能利用可观察的训练关系，
不能保证恢复数据编号携带但训练关系无法识别的隐藏信息。
