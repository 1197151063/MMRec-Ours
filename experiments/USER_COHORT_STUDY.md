# 同一物品消费者中的残余偏好：诊断与预测实验

目的：判断近编号用户在共同物品之外是否还有偏好相似性，以及不使用编号距离的邻居规则是否能预测隐藏交互。当前不改主模型，不保存模型，不承诺性能增益。

## A. 条件匹配诊断

只从 x_label=0 的二值交互 R 构建历史。每个 offset=1/4/16/64：

1. 从有共同训练物品的 (u,u+offset) 中随机取至多 4000 对。
2. 随机选择其一个共同物品 i。
3. 在 i 的消费者中找远距离对照 w，要求 |u-w|>256、deg(w)=deg(v)，且 |Iu∩Iw|=|Iu∩Iv|。u 不变，所以其度数也固定。
4. 找不到严格对照就跳过，报告覆盖率；不放松匹配条件，不反复换共同物品来强求匹配。
5. 对近、远两对分别移除其**全部共同物品**，再计算剩余历史相似性。无剩余历史或向量范数为零时是缺失值，不伪装成相似度零。

诊断视觉、文本：先按物品 L2 归一化原始特征，再求剩余历史的向量和与余弦。使用原始维度，不随机降维。

诊断协同：给每个用户独立高斯探针 Ωu，物品表示为 normalize(Rᵀ Du^(-1/2) Ω)。剩余历史用这些物品消费者分布的随机投影求和。它是 64 维近似，不是精确的图同构度量。探针不包含编号数值或距离；重新编号时必须同时置换探针。

报告 near_mean、far_mean、mean_paired_difference、near_wins、有效/缺失数；另分“仅共享一个物品”和“共享多个物品”。以 anchor user 为单位给出描述性 bootstrap 区间；由于物品和另一端用户可重复，不能把它直接当作严格的显著性检验。

匹配结果仅适用于有可匹配远端对照的用户对，不代表全部相邻用户；匹配还没有控制物品品牌、时间等不可用变量。

## B. 训练集内部隐藏交互预测

这一步不使用 A 的标签、距离或对照样本来训练/选边。

- 固定三个 mask seed：2026/2027/2028。
- 每个种子对所有训练度数>=3 的用户随机隐藏一条 TRAIN 交互，不只是隐藏查询用户的交互。
- 先隐藏，再重建候选集合、度数、用户历史和协同探针特征。
- 随机查询 2048 个可评估用户。正式验证集/测试集交互不参与，完整物品内容作为可用侧信息。
- 预测阶段图像/文本采用各自固定 64 维高斯投影，以降低大规模候选评分开销；与 A 的原始维度诊断有所不同。如 A 有明显信号而 B 无收益，需要进一步检查降维误差。

候选集为与查询用户有至少一个可见共同物品的其他用户。比较五种规则，每种 k=20/80，共 10 配置×3 次内部划分：

| 规则 | 邻居排名分数 |
|---|---|
| shared_cosine | c=共同物品数量/sqrt(双方度数乘积) |
| shared_random | 同候选集随机选邻居；同一组独立用户随机键 |
| residual_semantic | c × max(0, (剩余图像余弦+剩余文本余弦)/2) |
| residual_collaborative | c × max(0, 剩余协同余弦) |
| residual_joint | c × max(0, (剩余语义余弦+剩余协同余弦)/2) |

所有剩余分数均移除该用户对的全部共同物品；缺失值不建残余边。排名相同用独立用户随机键解开，不按 ID 大小或距离排序。这里是共享物品候选上的用户对筛选，没有假定存在离散群标签，也没有强制每个物品贡献等量邻居。

预测为所选邻居的平均投票，每位邻居贡献其按自身交互数归一化的可见历史。各方法统一用等权邻居，避免把排名规则变化与边权标度变化混在一起。排除查询用户的可见历史，对全部有正票物品排序；零票物品不随机补齐 top-k。目标不可达或没有邻居仍计入分母。

输出 Recall/NDCG@10/20、相对同 k 的 shared_cosine 的逐用户胜负数、候选目标覆盖率、实际邻居数。因为每个查询只有一个隐藏目标，此处 Recall@k 等于 HitRate@k。额外输出近编号边占比，仅作诊断，**不作为模型选择指标**。

这是快速的图信息价值筛查，不是 FreedomAlign 的性能，不应与论文 Baby 指标直接比较。多次 mask 也不是独立数据集复现。

## 决策依据

- A 无额外相似性：不能继续假设“编号邻近代表共同物品之外的偏好”。现有证据可能主要来自共同物品/原始文件排列。
- A 有差异、B 无提升：特征能描述群体，但暂未证明有推荐价值；查看投影误差、覆盖率和丢边情况，而不是直接加复杂主模型。
- B 在三个内部划分中稳定超过 shared_cosine 和 shared_random：再把该图接入主模型，单独验证一次残差聚合。选择依据是内部预测收益，最终只用正式验证集选主模型。
- B 有收益、A 无差异也可保留：有用的推荐图无需重现 ID 邻接。

预处理首次出现顺序只是待确认来源。仓库 notebook 的行为不能证明服务器 Baby 数据的实际生成流程；本实验不读取原始文件行号、首次出现次序、最小物品编号等替代顺序特征。
